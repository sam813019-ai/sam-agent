## 檔案結構：一個區塊一支檔

```
00_header.html      首屏（形象照 ＋ The Clean Edit ＋ 團主名牌 ＋ 開團倒數，含倒數 JS）
01_perks.html       三個好康（免運／前 100 名面膜／滿 4000 洗面乳）
02_items.html       團購品項 ×3（產品圖直接吃 Shopline 圖床；桌機一排三欄）
03_editorial.html   編輯風形象帶（第二張照片 ＋ 團主的話）← YB 版沒有，不要就刪掉這支
04_payment.html     付款方式（固定四項，無超商貨到付款）
05_picks.html       「詩芸的選物清單」主標題 ← 這段之後接 Shopline 全部商品
06_notice.html      注意事項

_shell_head.html / _shell_foot.html   整頁外殼（title／body 底色／頁尾）
build.sh            依編號組成 index.html
index.html          ← 自動產生，不要直接改
assets/             sy_hero.jpg（首屏，長邊 1200）、sy_editorial.jpg（編輯帶，長邊 1200）、
                    sy_avatar.jpg（名牌圓圖 400×400）
```

改法：改 `0X_*.html` → 跑 `bash build.sh` → `open index.html`。

## 配色（冷白編輯風）

取自詩芸的兩張形象照：白牆、黑絲絨沙發、白針織、裸膚色指甲。
每支區塊檔的 `<style>` 最上面都有一份相同的變數宣告，**改色要每支都改**（或整批 sed）。

| 變數 | 色值 | 用途 |
|---|---|---|
| `--ink` | `#1A1918` | 主色：標題、日期底、NEW／限量標籤底 |
| `--muted` | `#8B8783` | 次要文字、英文小標 |
| `--line` | `#E4E1DC` | 所有細線與卡片外框 |
| `--paper` / `--mist` | `#F7F6F3` / `#EFEDE9` | 頁面底色／圖框與注意事項底 |
| `--nude` / `--nude-soft` | `#C3A092` / `#EFE3DC` | 唯一的暖色點綴：編號、菱形、新品圖框 |

body 底色 `#F7F6F3` 在 `_shell_head.html`；首屏文字帶 `#FBFAF9 → #EDEBE7` 接照片頂端的白牆。
字體：中文標題 Noto Serif TC、內文 Noto Sans TC、英文小標與數字 Outfit、斜體標語 Cormorant Garamond。
