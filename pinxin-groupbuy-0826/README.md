## 檔案結構：一個區塊一支檔

```
00_header.html      首屏（形象照 ＋ 團主名牌 ＋ 開團倒數，含倒數 JS）
01_perks.html       開團好康
02_combos.html      主打組合（5 組）
03_prices.html      單品團購價（11 項）
04_addon.html       加購價（4 項）
05_calculator.html  團購試算（20 個品項，含加購擋關提示；含試算 JS）
06_payment.html     付款方式
07_shipping.html    運費說明 ＋ 出貨時程
08_service.html     客服資訊
09_notice.html      注意事項

_shell_head.html / _shell_foot.html   整頁外殼
build.sh            依編號組成 index.html
index.html          ← 自動產生，不要直接改
assets/             形象照、頭像、三支產品圖
```

改法：改 `0X_*.html` → 跑 `bash build.sh` → `open index.html`。
單獨看某一段也可以直接 `open 02_combos.html`。

## ⚠️ 需要你確認的地方

1. **贈品到底送什麼**：品馨分頁的備註寫「5000 **送蜜蜜霜**」，但同一頁最底下另一行寫
   「2000免運 5000**送洗面乳**」。兩者衝突，頁面目前寫成中性的「**送好禮**」，
   確認後改 `01_perks.html` 與 `05_calculator.html`（門檻文字）即可。
2. **商品全名**：試算表用的是內部簡稱，我推出的全名如下，請核對——
   - **洗安蜜 = 洗面乳＋水安瓶＋蜜蜜霜三件組**（1,080＋2,290＋2,290＝5,660，金額完全吻合）
   - 化妝水 = 魚子亮白化妝水；小水 = 同款 150ml
   - 面膜(盒) = 5D 養敷面膜（盒）；5D面膜 = 單片
   - 白膜淨 = 白膜淨去角質泥膜
   - **水安瓶／蜜蜜霜／膠囊** 我沿用簡稱，不確定官方全名。
3. **組合名稱是我取的**（三效防曬組、洗顏保濕組、全系列體驗組、B 群三入組），
   表上只寫「組合1～組合5」。要改直接改 `02_combos.html` 與 `05_calculator.html`。
4. **加購規則**「需與任一組合或單品一起買」是我依表上「加購」欄位推的，請確認是否正確。
5. **出貨時程**「團購結束後 3 個工作天內」沿用前一版團購頁的寫法，正式日期請確認。
6. 運費 $95／$65、客服電話、地址皆沿用既有團購頁。

## 沒有放進頁面的內部資訊

- 抽成 40%
- 備註「單品會員 9 折」——這是**定價邏輯**（單品團購價＝會員價再打折），不是給客人的優惠，所以沒寫上頁面。
- 備註「加購：推廣面膜單片・跑白膜淨・小水 5 入價」——說明加購品的定價由來（清庫存／推廣），同樣不對外。
