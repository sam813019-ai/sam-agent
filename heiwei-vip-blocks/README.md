# HEIWEI 何謂美 — 會員制度與福利頁

給 Shopline 自訂頁面用的會員制度說明區塊（對應 ZCJ `pages/vip` 那種頁面）。
純文字、無圖片、無 JS，貼上即可用。

| 檔案 | 用途 |
|---|---|
| **`vip_shopline.html`** | **要貼 Shopline 的就是這支。** 唯一真相來源 |
| `vip_artifact.html` | 預覽／給人看的版本，由 `make_artifact.sh` 自動產生，不要手改 |
| `make_artifact.sh` | 從 shopline 版加一層外框（標題、字型、底色）產生預覽版 |

## 上架步驟

1. Shopline 後台 → 網店設計 → 頁面 → 新增頁面（或編輯既有「會員制度」頁）
2. 加入「自訂 HTML／原始碼」區塊，貼上 `vip_shopline.html` **全部內容**
3. 存檔後用手機開一次，重點看：四張卡在手機是否單欄、達標路徑表格沒有水平捲動

改了 `vip_shopline.html` 之後跑一次 `bash make_artifact.sh` 同步預覽版。

## Shopline 過濾規則（沿用 heiwei-sunstick-blocks 的實測結果）

本檔已避開所有會被砍的東西：
CSS 變數、`<svg>`、`<details>`、`<script>`、字型 `@import`。
版面用 `display:table` / `table-cell`，不用 flex 與 grid，避免被主題 CSS 干擾。

## 設計

- 冷瓷白 `#F4F5F3` × 深炭墨 `#1F2220`，延續官網 v3 的編輯風調性
- 四張卡面純 CSS 金屬漸層：銀（冷灰）／金（香檳）／白金（冷鉑）／鑽石（深炭墨＋冰藍字）
- 金額一律 `tabular-nums`，四欄數字上下對齊

## 會員規則（2026-08-27 老闆確認）

- 升等是**逐階累積**：正式會員累計 1,000 → 銀卡；銀卡累計 3,000 → 金卡；金卡累計 10,000 → 白金卡；白金卡累計 80,000 → 鑽石卡
- 單筆消費達門檻同樣可直接取得該階資格
- 生日禮金**依發放當月的會員階級**計算，當月升等就發新階級的金額
- 紅利回饋：銀卡 2%／金卡 3%／白金卡 4%／鑽石卡 5%，依**下單當下的階級**計算
- 點數：1 點折 1 元、訂單滿 1,000 可折抵、折抵無上限、永久有效
- 原始文案在金卡／白金／鑽石三段都寫成「金卡會員累計滿 3,000 升級為金卡」，自己升自己不成立，已依上述規則改寫

## 版面

會員等級用**橫向對照表**呈現（參考 ZCJ 的 Member Level 表），列為項目、欄為四個等級：
會員等級（CSS 畫的卡面，無圖片）／取得方式／升等方式／紅利回饋／生日禮金／續會方式／會籍時間／新會員禮。
窄螢幕可左右捲動，第一欄項目名稱用 `position:sticky` 固定不動。
