# IOL 報告單代填工具 — 安裝與試用說明

## 你會拿到什麼

一個壓縮檔：`elden-iol-擴充功能-20260903.zip`

這是 Chrome 擴充功能的測試版，還沒上架 Chrome 線上商店，所以要用「開發人員模式」手動載入。
安裝過程不會動到你電腦上的其他東西。

## 安裝步驟（約 2 分鐘）

1. 把 zip **解壓縮**到一個**之後不會刪掉、不會搬動**的資料夾
   （建議：`文件` 底下開一個 `IOL代填工具` 資料夾）
   ⚠️ 這個資料夾刪掉或搬走，擴充功能就會失效

2. 打開 Chrome，網址列輸入：`chrome://extensions`

3. 右上角把 **「開發人員模式」** 打開

4. 左上角點 **「載入未封裝項目」**

5. 選擇剛才解壓縮出來的那個資料夾（裡面要看得到 `manifest.json`）

6. 清單上出現「Elden IOL 報告單代填」就成功了

## 怎麼用

1. 點 Chrome 工具列的擴充功能圖示（拼圖形狀），找到這個工具點一下，右側會開出面板
2. 第一次先點面板右上角的 **「設定」**，填醫師名稱、選常用的 SIA，儲存
3. 把報告單照片**拖進面板**，或點一下選檔案，或直接 Ctrl+V 貼上
4. **遮蔽畫面**：在照片上拖曳畫出黑框，蓋掉姓名、病歷號、生日
   - 下方顯示的就是會送出去的圖，請確認真的遮住了
   - 遮好之後可以取個名字「記住」，下次同一種報告單一鍵套用
   - 如果拍照前已經用紙蓋住個資，可以勾選下方的確認框直接送出
5. 按「確認送出辨識」，等 15～45 秒
6. 選擇要代填哪一隻眼
7. 逐欄核對「紙上讀到」與「將填入」兩欄的數字
8. 另開一個分頁打開計算器，回到面板按「填入計算器」

## 重要提醒

- **這個工具不會自動按 Calculate。** 計算一律由官方計算器執行，最終判斷以醫師為準。
- **A Constant 與 Lens Factor 不會被填入**，請自行在官網的 IOL Model 下拉選擇。
- **讀不到的欄位會留白**，不會亂猜。留白的欄位請人工填寫。
- 每次開 Chrome 可能會跳出「停用開發人員模式擴充功能」的提示，按「取消」即可繼續使用。
  正式上架商店後就不會有這個提示。

## 遇到問題請回報

請一併提供：
1. 那張報告單的照片（姓名病歷號可以先塗掉）
2. 畫面截圖，特別是紅色的錯誤訊息
3. 你當時做到哪一步

特別想知道：
- **計算器上第一個 K 欄位的標籤寫的是 Flat 還是 Steep？**（這關係到散光軸位會不會填反）
- 哪些欄位常常讀不到
- 遮蔽那一步會不會太麻煩
