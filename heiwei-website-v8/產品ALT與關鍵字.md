## 三、怎麼用這份關鍵字

1. **商品標題**：品牌＋商品名＋1～2 個 ★ 核心詞。例：「HEIWEI 爆白潤色防曬棒 SPF50+ PA++++｜潤色防曬棒 補擦不沾手」
2. **商品描述前 100 字**：把該品項的 ★ 詞自然放進去（Shopline 的 meta description 會抓前段）
3. **圖片 alt**：已補在九宮格；商品頁的圖也照本文第一段的寫法補
4. **廣告／團購文案**：從「痛點詞」下手——不黏膩、補擦不沾手、冷氣房救星、洗後不緊繃、妝前急救
5. **內容行銷**：每個品項的推薦文都在比「2026 XX 推薦」＋「Dcard/PTT」，可以寫同型標題的部落格或 Threads 貼文
