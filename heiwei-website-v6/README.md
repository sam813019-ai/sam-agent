# HEIWEI v6 —「光的一天」亮底版

v5 的亮底對照版。**結構、文案、互動與 v5 完全相同，只換配色系統**，方便直接比較深底 / 亮底哪個方向對。

```bash
cd heiwei-website-v6 && python3 -m http.server 8896   # → http://127.0.0.1:8896
```

## 與 v5 的差異（只有這些）

| 項目 | v5 | v6 |
|---|---|---|
| 主底 | `#131011` 暖黑 | `#F4EFE9` 暖米紙 |
| 區塊交替 | 深底 → 型錄亮底 | 米紙 ↔ 純白交替 |
| 強調色 | `#EFC4D2` 產品粉 | `#C4657F` 加深玫瑰（亮底上才有對比） |
| 光暈 | 暖橘 → 淡金 → 玫瑰（發光） | 蜜橘 → 象牙 → 粉玫瑰（陽光聚落） |
| 顆粒質感 | `overlay` 0.32 | `multiply` 0.16 |
| 產品陰影 | 黑 0.55 | 暖褐 0.22 |
| CTA 按鈕 | 粉底深字 | 深底米字（亮底上粉色按鈕對比不足） |
| 頁尾 | 同深底 | 深色收尾，替整頁收邊 |

## 亮底的兩個取捨

1. **強調色必須加深。** 產品本身的粉 `#EFC4D2` 放在米白底上對比不到 2:1，文字會看不清，所以文字用的粉加深成 `#C4657F`；產品圖本身的顏色沒動。
2. **產品需要更明確的陰影。** 深底靠發光把產品推出來，亮底只能靠陰影，所以 drop-shadow 從黑色改成暖褐色（純黑陰影在暖米底上會發灰）。

素材與轉檔流程見 `../heiwei-website-v5/README.md`，兩版共用同一套 101 張 WebP 影格。
