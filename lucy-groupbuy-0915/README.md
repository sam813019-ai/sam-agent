# Lucy × HEIWEI 何謂美｜夏季防曬保濕團（2026/9/15–9/20）

三品項團購頁：爆白潤色防曬棒（新品）、爆白防曬隔離噴霧、B 群保濕噴霧。

- **版型**＝品馨那版（形象照首屏＋團主名牌＋好康＋品項），商品本身用 Shopline 商品區塊呈現
- **品項**＝楠梓YB 那組（爆白噴霧／B 群噴霧／防曬棒），**價格**用報價表 Lucy 分頁
- **配色**＝「鮮果市集」，取自 Lucy 第一張形象照（暖奶油底／番茄紅／蜜橘／橄欖綠）

## 檔案結構：一個區塊一支檔

```
00_header.html      首屏（形象照 ＋ 團主名牌 ＋ 開團倒數，含倒數 JS）
01_perks.html       開團好康（免運／贈品門檻）
02_items.html       團購品項（產品圖直接吃 Shopline 圖床，不放 assets）
03_payment.html     付款方式
04_picks.html       「Lucy 的愛用清單」主標題 ← 這段之後接 Shopline 全部商品
05_notice.html      注意事項

_shell_head.html / _shell_foot.html   整頁外殼（title／body 底色／頁尾）
build.sh            依編號組成 index.html
index.html          ← 自動產生，不要直接改
assets/             lucy_hero.jpg（首屏）、lucy_avatar.jpg（團主名牌小圖）

── 已從頁面移除（檔名前面加底線，build.sh 會略過，要復活就把底線拿掉並補編號）──
_03_combos.html     主打組合
_04_prices.html     單品團購價
_05_calculator.html 團購試算
_07_shipping.html   運費說明 ＋ 出貨時程
_08_service.html    客服資訊
```

改法：改 `0X_*.html` → 跑 `bash build.sh` → `open index.html`。單獨看某一段可直接 `open 05_notice.html`。

## 配色（鮮果市集）

每支區塊檔的 `<style>` 最上面都有一份相同的變數宣告，改色要**每支都改**（或整批 sed）：

| 變數 | 色值 | 用途 |
|---|---|---|
| `--fruit` | `#E0533C` 番茄紅 | 主色：標題色塊、按鈕邊、進度條 |
| `--fruit-dk` | `#B33C29` | 標題字、價格數字 |
| `--fruit-soft` / `--fruit-mist` | `#FBE0D8` / `#FEF5F1` | 淺底、表頭底 |
| `--citrus` / `--citrus-soft` | `#E8913F` 蜜橘 / `#FDEFDD` | 副色：NEW 標籤、新品卡片 |
| `--ok` | `#5F7F52` 橄欖綠 | 「省 $XXX」、門檻達成 |
| `--ink` / `--muted` / `--line` | `#2C2A28` / `#7A6C63` / `#F0E2D8` | 文字與線 |

body 底色 `#FFF9F2` 在 `_shell_head.html`。
