# 本週（8/31–9/2，進行中）

## 1.1 網站維護與細節優化

**v7 動畫頁 sticky 問題深度排查**（8/31）
- 上線後動畫仍不正常，逐層排查後找到真正原因：
  `body` 本身設了 `overflow-x:hidden`，使其成為「不會捲動的捲動容器」，
  導致內部 `position:sticky` 永遠不觸發
- 此問題本機模擬環境測不出來（模擬檔只複製了 `.CustomPage` 的 overflow，沒複製 body/html 的）
- 另發現 Shopline 用 Angular 動態注入，腳本執行當下元素可能尚未掛載，解鎖需延後重試
- 狀態：已修正，實測正常

**Shopline 版面區塊製作**（9/1）
- 頂部橫幅獨立版（從動畫頁抽出捲軸旋轉動畫段落，可單獨使用）
- 超商取貨送咖啡券跑馬燈（純 CSS，不需 JS）
- 爆白潤色防曬棒常見問答區塊（另做商品描述專用版，全部改用 inline style 以通過過濾）
- 狀態：已完成

## 1.4 素材與視覺規劃

**首頁 Banner 尺寸規格確認**（9/2）
- 查證 Shopline Varm 版型官方建議值，確認規格：
  **桌機 1920×800**（官方推薦的滿版尺寸）、**手機 1200×1500**（4:5）
- 手機比例選 4:5 而非官方列的 3:4：較矮可多露出下方內容，且與 IG 貼文同比例、社群素材可共用
- 寬度用 1200 而非 1080：覆蓋 iPhone 15／Pro Max 的實際像素寬度
- 補充：輪播元件需開啟「同高第一張輪播圖」避免裁切；重點文字避開上下各 15%；檔案壓縮至 200KB 內
