WEBSITE AUDIT REPORT

FLYING CASE 官網健檢報告 flying-case.com ｜ 木箱起飛影像有限公司

本報告以實際抓取全站 HTML 原始碼、逐一量測每個資源的實際檔案大小（HTTP content-length）為依據， 非目視推測。涵蓋首頁、關於我們、作品展示、應用產業、服務項目、聯絡我們，以及 sitemap 中的所有頁面。

總結一句話：素材與內容都有，但「首頁沒有內容、作品頁沒有說明、圖片肥到手機打不開」 這三件事，讓網站目前幾乎無法替公司帶來詢價。三項都屬於可在兩週內修復的問題，且第一項的投報率遠高於其他所有優化的總和。

01頁面重量爆炸

逐一量測每頁所有資源的實際傳輸大小後，結果如下：

頁面路徑實測總重量
服務項目/services/246.3 MB
關於我們/關於我們/152.8 MB
首頁/121.6 MB
作品展示/gallery/83.9 MB
應用產業/應用產業/12.5 MB
聯絡我們/contact/0.2 MB

單一檔案最大的三個：義享天地GIF.gif 134 MB、 首頁 e9a696e9a081gif.gif 78 MB、 首頁影片 2021-flyingcase-showreal.mp4 121 MB。

影響：4G 手機開服務項目頁需下載 246MB，約需 3–8 分鐘，並直接消耗客戶的行動數據。 實務上絕大多數訪客會在 5 秒內離開；Google 也會因 Core Web Vitals 不合格而壓低排名。

解法：所有 GIF 一律轉成 MP4，體積通常只剩原檔的 1–5%。 
ffmpeg -i input.gif -vcodec libx264 -crf 24 -pix_fmt yuv420p \
  -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" -movflags +faststart output.mp4
好消息：貴司的 /應用產業/ 這一頁已經做對了—— 全部使用 h264 MP4、附 poster 首幀，整頁只有 12.5 MB。這頁就是全站的標準範本， 把同樣做法套回首頁、作品展示與服務項目即可。

另外首頁影片檔名為 2021-flyingcase-showreal：一是 2021 年的舊 reel， 二是拼字誤植（showreal 應為 showreel）。建議更換 2026 年版本、壓至 10–20 MB、並加上首幀 poster。

02首頁完全沒有文字

首頁的實際 DOM 結構為：header ＋ 一個 700px 高的影片區塊 ＋ 一個空的 <p> ＋ footer。 沒有標題、沒有一句話說明公司在做什麼、沒有行動呼籲、沒有作品、沒有客戶名單。全頁唯一的 <h1> 是站台名稱。

影響：訪客進站只看到一支無聲影片，不知道下一步該按哪裡；Google 抓不到任何可排名的文字內容。

建議首頁結構：
  • Hero — showreel ＋ 一句定位文案 ＋ 兩顆按鈕（看作品 / 聊需求）
  • 精選案例 3–6 支（務必附客戶名稱）
  • 四大服務：影像製作 / 特效 / 3D 建模 / 裸視 3D
  • 合作客戶 Logo 牆
  • 製作流程與交期說明
  • 聯絡 CTA

03作品展示頁等於沒有作品

/gallery/ 全頁只有 4 顆 GIF 按鈕（合計 88 MB、alt 屬性全為空值）， 點進去後的 /249-2/、/257-2/、 /269-2/、/281-2/ 每頁就是 7 支裸露的 YouTube iframe——沒有標題、沒有客戶名、沒有任何一個字說明「這支我們做了什麼」。

影像製作公司最貴的資產就是作品頁，這頁目前的說服力接近於零。

每支作品至少補上：客戶／品牌名稱、片型（MV / TVC / 形象片 / 3D 動畫）、 我方負責的環節（前期企劃 / 拍攝 / 3D / 合成 / 剪輯 / 調色）、一句話的挑戰與解法、年份與片長。

URL 也應一併調整：/249-2/ → /works/3d/、 /257-2/ → /works/mv/、 /269-2/ → /works/cf/、 /281-2/ → /works/reel/。

P1影響轉單直接影響詢價率與專業觀感

04導覽列有一半連到舊網址

Showcase、Services、Contact 三個主選單連結指向 waynebear20996-qbpja.wordpress.com/...。雖然會 301 轉回正式網域， 但多一次跳轉，而且滑鼠一 hover 就會在瀏覽器狀態列露出 wordpress.com 測試網址——B2B 客戶看到會扣分。

解法：三個連結改為站內相對路徑（/gallery/、 /services/、/contact/）。

05每頁底部都掛著留言板

首頁以外的每一頁底部都出現「載入迴響中…／發表迴響…／電子郵件（必要）／名稱（必要）／網站」。 企業官網不應有公開留言區，除了觀感不專業，也會成為垃圾留言的入口。

解法：於 WordPress 後台關閉所有 Page 的 comments（討論設定 → 取消勾選「允許留言」）。

06完全沒有任何追蹤代碼

全站原始碼中找不到 GA4、Google Tag Manager、Meta Pixel 或任何分析工具。 等於不知道流量從哪裡來、哪一頁跳出率最高、哪支作品最多人看、詢價從哪個管道進來。

解法：最低限度先裝 GA4；若有投放 FB／IG 廣告需求，一併加上 Meta Pixel。

07聯絡頁資訊過於單薄

目前表單只有姓名／電子郵件／訊息三個欄位，收到的詢價幾乎無法判斷輕重與可行性。 電話 07-3436111 也沒有做成 tel: 連結，手機無法點擊撥號。

建議加上：公司名稱、需求類型（MV / TVC / 3D 建模 / 網站 / 線上展館）、 預算區間、期望上線日期；頁面另補公司地址 ＋ Google Map 嵌入 ＋ 統一編號 ＋ LINE 官方帳號 QR Code。

08沒有結構化資料（Schema）

全站找不到任何 application/ld+json 標記。

解法：加入 Organization 與 LocalBusiness schema（公司名、Logo、電話、地址、社群連結）， 讓 Google 搜尋「木箱起飛」時能顯示知識面板與地圖資訊。

09SEO 標題與描述設定不當

首頁 <title> 塞入了長達 105 字的整段公司介紹，Google 搜尋結果只會顯示前約 30 字， 其餘全部被截斷。/gallery/ 更是連 meta description 都沒有。

建議首頁標題改為：
FLYING CASE 木箱起飛影像｜高雄 3D 動畫・特效・TVC/MV 影片製作
並為每一頁補上 60–80 字、含關鍵字的 meta description。

P2收尾細節不急，但做完整體質感會明顯不同

10孤兒頁與重複內容仍留在 sitemap

  • /2025/08/05/hello-world/ — WordPress 預設的「Hello World!」文章仍公開發佈中，建議直接刪除
  • /team/（Crew）— 站內沒有任何入口可以連到
  • /film-3d-showcase/ 與 /應用產業/ 內容完全重複，會互相稀釋 SEO 權重 → 擇一設 canonical 或改為 noindex

11同一頁出現兩個 H1

/應用產業/ 同時有站台名稱與頁面標題兩個 <h1>。 站台名稱應改用 <p> 或 <div>，每頁只保留一個 H1。

12圖片 alt 大量缺失

作品展示頁四顆按鈕的 alt 全為空字串； 服務項目頁的 001~010 圖檔也沒有描述性 alt。 這同時影響無障礙與圖片搜尋流量。

13同頁 9 支影片同時自動播放

/應用產業/ 頁面內有 9 支 autoplay loop 影片同時播放， 手機省電模式會直接阻擋，且非常耗電與耗流量。

解法：改為 preload="none" ＋ 點擊播放，或平時只顯示 poster 靜態圖。

14沒有英文版

既有 AC600 換箱機這類設備商客戶，也承接政府標案，建議增設 /en/ 英文版， 至少涵蓋首頁、服務、作品三頁。

15頁尾仍掛著 WordPress.com 官方工具列

訪客可見「註冊／登入／複製短網址／回報此內容／管理訂閱」等 WordPress.com 官方連結 （wpcom-actionbar），會削弱自有品牌感。升級方案後可移除。

本週最省力的三件事投報率由高至低排序

1. 把 6 支大 GIF 全部轉成 MP4
全站總重量可從約 600 MB 降至約 15 MB。這一件事的效益，大過其他所有優化加起來的總和。
效益 ★★★
2. 首頁補上一屏文案 ＋ 兩顆 CTA ＋ 精選 6 支作品
讓訪客在 5 秒內知道「你們是誰、做什麼、下一步按哪裡」。
效益 ★★★
3. 導覽列三個連結改回 flying-case.com，並關掉留言區
兩個後台設定即可完成，耗時約 10 分鐘。
效益 ★★

接續第二階段（2–4 週）

4. 重做作品展示頁
每支作品補上客戶名、片型、我方負責環節、年份片長；URL 改為語意化路徑。
5. 安裝 GA4（必要時加 Meta Pixel）
開始累積流量與轉換資料，後續優化才有依據。
6. 擴充聯絡表單欄位，電話改為可點擊撥號
加入公司名、需求類型、預算區間、期望上線日；補地址、Google Map、統編、LINE QR。
7. 修正 SEO 標題與描述，加入 Organization Schema
首頁標題縮短為 30 字內；每頁補 meta description。
8. 清理孤兒頁與重複內容
刪除 Hello World! 文章；處理 /film-3d-showcase/ 與 /應用產業/ 的重複。
