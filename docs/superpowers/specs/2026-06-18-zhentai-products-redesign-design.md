# 振太機械 products.html 產品改版設計

日期：2026-06-18
範圍：`振太網站/products.html` 產品線區塊（四大系列）

## 目標（使用者需求）

1. **排序修正**：依 docx《振太網站產品系列》原始順序排列，左上角第一個＝送料系列「1.整組振動送料機系列」。目前 WP 回傳順序顛倒。
2. **紅字 / 黑字顯示模式**：
   - 🔴 紅字產品 → 產品資訊卡左側顯示 **PNG 大圖**
   - ⚫ 黑字產品 → 左側用 **360° 拖曳旋轉**（同羅拉篩選機）；無素材時顯示「360° 準備中」佔位符
3. **子項目群組**：部分品項含多個子項（如「控制器配件」8 項），點入後 **一次以網格呈現全部子項**（截圖範例）。
4. **資訊卡等比例放大**：modal 從 960px 放大至約 1180px。

## 架構決策

- **資料來源改為檔案內建**（使用者已選定）：以 products.html 內的 JS 產品陣列取代現行 WordPress REST(`jt-products`) fetch。完全掌控排序、模式、子項目。
- 360° 影格與 PNG 圖為靜態素材，置於 `/wp-content/uploads/zhentai/...`，由使用者陸續補上；缺素材時顯示佔位符。
- 圖片路徑沿用 Drive 的中文檔名 1:1（降低使用者管理負擔），JS 以 `encodeURI()` 處理。

## 資料模型

```js
const SERIES = [
  { slug:'feeding-orientation', zh:'送料(選向)系列', en:'Feeding (Orientation) Series' },
  { slug:'replenishing',        zh:'補料系列',       en:'Replenishing Series' },
  { slug:'sorting',             zh:'篩選系列',       en:'Sorting Series' },
  { slug:'machinery',           zh:'機械系列',       en:'Machinery Series' },
];

// 圖片基底（WP 上線路徑）
const IMG_BASE = '/wp-content/uploads/zhentai/products-img/';

// 產品物件
{
  no: 1,
  series: 'feeding-orientation',
  nameZh: '整組振動送料機系列',
  nameEn: 'VIBRATORY FEEDER SERIES',
  model: '',
  mode: 'png' | '360' | 'group',   // 紅字=png、黑字=360、有子項=group
  image: '送料(選向)系列/整組振動送料機系列.png' | null,
  frames: null,                     // 360 影格 base url；null=佔位符
  specs: [ {label, value, highlight?} ],
  subItems: [ { nameZh, nameEn, mode, image, frames } ]  // 僅 group
}
```

### 統一顯示邏輯（modal 左側）
1. `group` → 子項目網格（每格圖＋中英名）。
2. 否則：有 `frames` → 360° 檢視器；否則有 `image` → 靜態 PNG；否則 → 「360° 準備中」佔位符。

> 註：少數黑字產品（渦電流、層斗式、隔音箱）Drive 已有 PNG。依上述邏輯，黑字無 360° 影格時會自動改顯示其 PNG，不浪費素材；待使用者補影格後自動切回 360°。卡片角標：png→「VIEW PHOTO」、360→「VIEW 3D」。

## Modal 變更
- 寬度 `min(960px,100%)` → `min(1180px,96vw)`；viewer 與 info 內距等比放大。
- 新增 `group` 版面：左欄改為子項目響應式網格（2–4 欄，每格圖＋名稱），右欄為群組說明。
- `png` 模式：左欄顯示 `<img object-fit:contain>` 取代 canvas。

## 圖片素材流程
- Drive「產品照片for網站」4 系列資料夾檔名已與產品名對齊。
- 因 Google Drive 搜尋 API 索引延遲，現只能漸進抓取；採以下其一取得：
  1. 使用者下載 4 個系列資料夾 → 解壓至 `振太網站/products-img/<系列>/`（最快可靠）
  2. 索引更新後由 MCP 批次下載
- 取得後上傳 WP `uploads/zhentai/products-img/`。缺圖期間顯示佔位符，不影響上線。
