## 2. 讀取方式（擇一）

- **方法 A（最簡單）**：若執行的 Claude 有 Google Sheets 存取權，且此試算表已分享給該帳號 → 直接讀 `美容展抽獎兌換紀錄!A2:H`。
- **方法 B（本次實際使用）**：此表沒有分享到 Google 連接器、且 Google 服務帳號金鑰存在 Vercel 的 Sensitive 環境變數（本機／連接器拿不到）→ 在 `heiwei-expo-wheel` 這個 Vercel 專案臨時建立一支「服務帳號讀取端點」：
  - 環境變數：`GOOGLE_SERVICE_ACCOUNT_EMAIL`、`GOOGLE_PRIVATE_KEY`、`EXPO_SHEET_ID`
  - scope：`https://www.googleapis.com/auth/spreadsheets.readonly`
  - 讀取 `美容展抽獎兌換紀錄!A2:H` 後回傳，**用完即刪端點**（避免留下讀取後門）。
  - ⚠️ 此方法需要能部署 Vercel（一般 Claude 對話做不到，需 Claude Code 或 CLI 環境）。

只需要取用兩欄：**A 抽獎時間（t）** 與 **E 獎項（prize）**（其餘含個資，不需取用）。

## 3. 時間解析（重點，容易踩雷）

- A 欄時間格式來自 JS `new Date().toLocaleString('zh-TW', { timeZone: 'Asia/Taipei' })`
  - 範例：`2026/8/11 下午12:38:28`
- ⚠️ **日期與時間之間是「窄空格」U+2009**，不是一般半形空白 —— 解析前先把各種空白正規化。
- 建議正則：`(\d+)/(\d+)/(\d+)\s*(上午|下午)?(\d+):(\d+)`
- 轉 24 小時制：
  - `下午` 且 小時 ≠ 12 → 小時 + 12
  - `上午` 且 小時 == 12 → 小時 = 0

## 4. 統計邏輯

1. **每天流量**：依「日期（YYYY/MM/DD）」分組計數。
2. **時段分布**：依「小時（0–23）」分組計數，取尖峰 TOP3。
3. **各獎項數量**：依 E 欄獎項分組計數（由多到少）。
4. **洞察**：把「單日暴衝的日子」對照「LINE 推播發送日」（通常暴衝＝推播帶量）；找出黃金時段（本次結果為中午 12 點、深夜 22–23 點雙尖峰）。

- 3–5 點洞察（尖峰日對應推播、黃金發文時段、獎項分佈是否符合權重設定）
