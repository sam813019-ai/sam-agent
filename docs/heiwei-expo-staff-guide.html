A

現場抽獎

轉到就給 · 免核銷
攤位平板／手機上的轉盤，客人現場玩、現場領。
  1. 客人完成消費後，打開轉盤頁 /onsite，交給客人或由你操作。
  2. 按下「開始抽獎」，轉盤停止後，畫面會用大字顯示中獎獎項。
  3. 依畫面大字顯示的獎項，當場把該獎品交給客人。
  4. 按「下一位 · 再抽一次」回到待機畫面，換下一位客人。
注意事項
  • 不需登入、不用 Email、不用兌換碼、不用核銷。
  • 一律以畫面大字為準。某獎發完時，系統會自動不再中該獎、改給保底獎。
  • 平板請由工作人員保管，一位客人轉一次。
B

線上抽獎

需兌換碼 · 要核銷
客人在 LINE 官方帳號 @heiwei 抽獎，中獎後拿兌換碼到攤位領。
  1. 客人加入 @heiwei 好友，從官方帳號進入抽獎頁。
  2. 客人用 LINE 登入並填 Email，轉動幸運盤（每人限抽一次）。
  3. 抽中後，客人會收到 LINE 通知與一組兌換碼（格式 HW-XXXXX）。
  4. 客人憑兌換碼到攤位兌換 → 由工作人員核銷發獎（見下方 C）。
給同仁的提醒
  • 線上中獎的獎品一定要核銷才發，避免同一組碼重複領。
  • 客人若還沒加 @heiwei，可引導他加好友後即可抽。
C

兌換核銷流程

線上中獎專用
只有「線上抽獎」的兌換碼需要核銷；現場轉盤不用。
  1. 客人出示 LINE 收到的兌換碼（畫面或截圖，HW-XXXXX）。
  2. 打開核銷頁 /staff，輸入工作人員 PIN 4523。
  3. 輸入客人的兌換碼，按「確認核銷」。
  4. 系統顯示中獎獎項 → 把對應獎品交給客人，完成。
重要規則
  • 每組兌換碼限用一次，核銷後即失效、不可重複領取。
  • 若客人畫面顯示的獎項與系統不符，一律以系統核銷結果為準。
  • 想先確認碼是否用過，可用「只查詢狀態」查詢，不會扣銷。
D

獎項管理後台

負責人專用
調整獎項、機率與庫存的地方。一般工作人員請勿更動。
  1. 打開 /admin，輸入 PIN 4523。
  2. 可新增／刪除獎項、調整中獎機率、每日限量、總量限制、啟用停用。
  3. 每個獎項會即時顯示「發出／剩餘」庫存，方便盯量。
  4. 改完按「儲存」，約即時生效（同步現場與線上轉盤）。
常見情況
  • 某獎發完了：系統會自動改給保底獎；要完全下架該獎，由負責人到 /admin 停用。
  • 要臨時加獎或改機率：負責人在 /admin 改完儲存即可，不必動系統。
現場排除狀況
  • 轉盤打不開／轉不動：先確認平板有連上網路（Wi-Fi 或手機熱點），重新整理頁面。
  • 核銷顯示「查無此碼／已領取」：以系統為準；請客人確認是否為正確的兌換碼或已領過。
  • 其他系統問題，請聯繫現場負責人處理，勿自行更動 /admin 設定。
