商店配色調整

把 Shopline 主題「色彩」面板裡的十組設定、共 20 個色欄位，對齊「光的一天」v7 的視覺語彙。
現況有兩處對比度不合格，另有一項改了會出事——先看第一段。

01先別按發佈：頁面背景不能設黑

你後台的「頁面 → 背景」已經改成黑色（線上還是白的，代表還沒發佈）。 這一項發佈出去會出事，其他項都可以改，只有這個不行。

每張商品圖都會變成一個白方塊

我抓了 vitamin-b-water 的商品圖實測：

  • 透明像素 0.0%——圖片沒有去背，alpha 全部是 255
  • 90.8% 的像素是不透明的近白色 #FEFEFE
  • varm 主題的商品卡沒有自己的白底，圖是直接坐在頁面背景上

三個條件加起來，黑底上會浮出一格一格的白方塊。v5 那次就是踩這個坑， v7 自己也是這樣處理——深底走到型錄段就換亮底 #F6F2EE，因為那段要放商品圖。

要真的做深底商店，唯一的路是把商品圖全部去背重出（或重拍）。 在那之前，頁面背景請維持 #ffffff。

02另外三個問題

數字是 WCAG 對比度，內文需要 4.5:1 以上才算合格。

1.24

防詐騙提示幾乎看不見

底色 #121A2F 深藍配 #2c2c2c 深灰字。深藍是主題預設值沒改到， 跟整站米色系也毫無關係。這不是美感問題，是壞掉。

2.44

連結金褐在白底上讀不出來

#bfa26c 在白底只有 2.44:1。商品描述裡的連結客人會看不到。

4.11

五個地方共用同一個米灰

公告欄、主要按鈕、立即購買、促銷標籤、頁尾底全是 #e0d9d1。 整站沒有層次，最傷的是 CTA 按鈕跟背景融在一起，客人找不到「加入購物車」在哪。

06建議的執行順序

  1. 把頁面背景改回白色—— 在商品圖去背之前不能發佈黑底
  2. 防詐騙提示—— 這是壞的，先修，兩分鐘
  3. 主要按鈕改深炭—— 對轉換率影響最大，CTA 終於看得見
  4. 頁尾改深炭—— 讓 v7 那頁的深色頁尾接得起來
  5. 連結色—— 影響所有商品描述裡的連結
  6. 其餘四項（頁面文字、公告欄、頁首、促銷標籤、版權）一次改完

07那要怎麼有深色感

很想這樣做，但 Shopline 的商品圖全是白底拍攝——v5 那次就踩過， 白底商品圖放在暗底上會浮出一塊塊白方塊，很難看。v7 自己也是這樣處理的： 深底走到型錄段就換成亮底 #F6F2EE，因為那段要放商品圖。

所以商店端維持白底為主，只把「品牌訊號」——公告欄、按鈕、頁尾——換成深炭， 形成深色的框把白色內容包住。這樣既跟 v7 是同一個世界，商品圖也不會出事。
