三品項團購頁：爆白防曬隔離噴霧、B 群保濕噴霧、**新品爆白潤色防曬棒**。
資料來源＝報價表「**楠梓YB**」分頁（抽成 30%，1000 免運／4000 送洗面乳）。

## 檔案結構：一個區塊一支檔

```
00_header.html      首屏 ＋ 開團倒數（含倒數 JS）
01_items.html       團購品項
02_prices.html      單品團購價
03_combos.html      組合優惠
04_calculator.html  團購試算（含試算 JS）
05_perks.html       下單好康
06_payment.html     付款方式
07_shipping.html    運費說明 ＋ 出貨時程
08_service.html     客服資訊
09_notice.html      注意事項

_shell_head.html    整頁外殼（開頭：doctype／title／body 底色）
_shell_foot.html    整頁外殼（結尾：頁尾）
build.sh            把上面全部依編號組成 index.html
index.html          ← 自動產生，不要直接改
assets/             三支產品圖
```

## 怎麼改

1. 改對應的 `0X_*.html`（每支都自帶 `<style>`，改這支不會影響其他區塊）
2. 跑 `bash build.sh`
3. `open index.html` 看結果

只想看單一區塊也可以直接 `open 02_prices.html`，圖片路徑一樣抓得到。

**調整順序**：改檔名前面的兩位數編號即可（檔名格式固定為 `數字數字_名稱.html`）。
例如想把組合優惠排到品項後面，就把 `03_combos.html` 改成 `02_combos.html`、原本的 `02_prices.html` 改成 `03_prices.html`。
**移除區塊**：把那支檔案改名成 `_03_combos.html`（前面加底線），`build.sh` 就會略過它。
**新增區塊**：複製任何一支當範本，改 class 名稱與編號即可。
